# Run report: 2026-10-15-deletion, batch b1 (closed 2026-10-15)

**Verdict:** 12 of 13 findings are fixed. 5 are verified. 7 are verified in the code but still need a check on the phone. UX-804 is still open because the part that's left is on the server. Nothing was escalated. The tests passed in both rounds.

**Evidence:** the code (`git diff HEAD`) and ux-tester's widget and unit tests in `App/test/delete_account_test.dart`. No preview renders the delete page or Account, so no visual judgement here rests on an image. Nothing ran on an emulator or a phone.

## Verified (the reviewer said fixed, and the tests pass)
- **UX-801**: The wrong-password message now explains how to get back in: sign out («Cerrar sesión»), then use «¿Has olvidado tu contraseña?» on sign-in. It's in EN, ES and CA, and the field shows up to 10 error lines (`errorMaxLines: 10`). Recovering without leaving the page is UX-815, which is still waiting on the owner's decision.
- **UX-802**: When the account has files, «La copia no incluye los archivos.» appears under the copy link, or under «Copia guardada». Whether the copy should include the files is UX-814, a decision.
- **UX-805**: After a conflict, «Algo ha cambiado» now lists each handover that is new or changed. That line is bold in the list until the next tap.
- **UX-809**: «Espera N minutos» now uses the wait time the server sends, rounded up. If the server sends no wait, the old message shows.
- **UX-811**: On Account, Eliminar cuenta now sits 24 dp below Cerrar sesión with a divider between them. It stays last and red.

## Verified in the code, still needs the phone
- **UX-807**: «Guardar antes una copia» saves the export directly, and «Copia guardada» replaces the link.
- **UX-808**: While the account is being deleted, the button reads «Eliminando tu cuenta…» and the back arrow is hidden.
- **UX-810**: «Confirmado con Google» is announced to TalkBack, and «Eliminar mi cuenta» scrolls into view.
- **UX-803**: The page shows the account's email under the heading, and the Google lines name that email and say the Google account stays.
- **UX-806**: Complimentary Pro users and users without Pro see no Google Play line. «Gestionar suscripción» opens the Customer Center or Play's subscriptions page.
- **UX-816** (regression R1D-1): The title no longer jumps sideways while the account is being deleted, because the back-button slot keeps its width, empty.
- **UX-817** (regression R1D-2): The changed-plan banner is announced only once, after the reload finishes, and TalkBack no longer reads «viñeta».

## Still open
- **UX-804**: What stays reads like more of what goes. The reviewer marked it **partly** fixed in round 1.
  - Done in the app and tested: two lists under headings, a kept line that gives the count first and names the files, and each group's projects named.
  - Still missing: someone who added only files to shared projects sees no kept line. The cause is on the server: `kept_in_shared` (`Backend/core/account_deletion.py:106`) counts only tasks. It wasn't re-planned and it hasn't failed twice, so it isn't escalated. It needs server work.
