**Evidence level:** code review (git diff HEAD) plus ux-tester's widget and unit tests. There was no rendered preview of the delete page, so nothing was judged from a render. Nothing was run on an emulator or a physical phone.

### Verified
- **UX-804** (S2, D): What stays reads like more of what goes. Reviewer: fixed (verify-b2-r1-D).
  - This closes the server-side gap left open in b1. The app now reads `kept_files_in_shared` and uses 0 when the key is missing (`App/lib/services/account_deletion.dart:66-68, 107-109`).
  - It adds a files bullet under «Lo que se queda para los demás:», after the tasks bullet and before the handovers (`App/lib/screens/delete_account_screen.dart:504-505`).
  - That heading now shows when only files stay. When nothing stays, neither the heading nor the files line shows.
  - Copy, with singular and plural forms and no final full stop:
    - EN "1 file / {n} files you added to shared projects, without your name"
    - ES «1 archivo / {n} archivos que añadiste a proyectos compartidos, sin tu nombre»
    - CA «1 fitxer / {n} fitxers que vas afegir a projectes compartits, sense el teu nom»
  - The tasks line no longer says «y los archivos». That claim was false for someone who added tasks but no files.
  - On the server, files on deleted tasks are left out of the kept count (`Backend/core/account_deletion.py:108-110`), so no file is counted in both lists.
- **UX-809** (S2, D): «Inténtalo más tarde» hides a 15-minute lock. Already verified in b1; re-verified now (reviewer: fixed).
  - `ApiException` now carries the whole-seconds `Retry-After` header (`App/lib/services/api_client.dart:470-480`). A missing header, a negative value or an HTTP date gives null.
  - The delete page takes the wait from that header first, then from the English detail text, and otherwise shows the generic line (`delete_account_screen.dart:182-191`).
  - The server's `Throttled(wait=900)` makes DRF send `Retry-After: 900`, so a Spanish detail text still produces «Espera 15 minutos».
