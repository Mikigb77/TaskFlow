### Regressions (changed files and the flows they touch)
None found.
- `ChecklistEditor` early return: the disabled field keeps its text (shown greyed through `enabled: onChanged != null`). If the save fails, the card re-enables with the text still there. Enter can't reach `_addStep` on a disabled field.
- Capture `_save`: `_saving` is set before the microtask without a rebuild, so the button looks active for one microtask, which nobody can see. Re-entry, `_leave` and an empty `ready` all behave as before. Inline rename also commits before the card is disabled, because `_renameLeft` runs in the same microtask.
- TaskEditor: the `_quickDate` removal in this diff is dead code (`grep` finds no other use). `_save` and `_back` already unfocus first.

### Notes (not regressions)
- Collapsed form: removing the last step through ⋮ hides the step section, and any text in `Añadir paso` goes with it. This is an edge case that predates this round; the same unfocus-before-toggle idea doesn't apply, so it's only noted.
